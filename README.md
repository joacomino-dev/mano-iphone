# CocoWash — mano-iphone
App personal para revisar y organizar Fotos de iPhone con una mano de cartas. Análisis local, sellos y borrado por sesión.

**Versión aprobada: 0.9.7, build 18.** El usuario confirmó pruebas en iPhone y una experiencia fluida el 4 de noviembre de 2026; autorizó convertirla en la versión actual de `main`.
